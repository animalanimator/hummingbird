# Hummingbird 3D: rig, weight paint & 6 core animations

The current state of the [Animal Animator](https://animalanimator.com/) 3D hummingbird (v1, "Core Animations"). **Hummingbird v2 is in progress.**

- Full reference: [The ultimate hummingbird reference for animal animators](https://animalanimator.com/the-ultimate-hummingbird-reference-for-animal-animators/)
- 3D model (free GLB): [Sketchfab](https://sketchfab.com/3d-models/hummingbird-rigged-6-animations-open-bill-d9b448ac1025485e843d54bebf35390a)
- This repository is a GitHub Pages site: `index.html` plus `videos/`, `images/` and `downloads/`.

| Folder | Contents |
|---|---|
| `videos/` | The six core clips (Blender EEVEE, 1280×720, 60 fps, H.264) with poster images |
| `images/` | Pipeline figures: rig, weight paint, bill, mouth corner, tongue, claws |
| `downloads/` | `hummingbird_v1_core_animations.blend` (bird + rig + 6 actions + props, textures packed) and `hummingbird_v1_rig_only.blend` (armature + 6 actions). Clean copies: no scripts, custom properties, file paths or UI layout. Saved with Blender 5.1. |
